# Marketing Campaign Impact (Difference-in-Differences)

Estimate causal impact of a marketing campaign using a diff-in-diff design on
synthetic panel data.

## What it covers
- Synthetic panel data generation
- Pre/post treatment structure
- Difference-in-differences regression
- Simple effect interpretation

## Run
```bash
python projects/causal_inference/campaign_diff_in_diff/train.py
```

## Output
- Prints the estimated treatment effect and a short summary.
