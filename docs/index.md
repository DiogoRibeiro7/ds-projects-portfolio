## Why This Toolkit

- **End-to-end experimentation**: full stack of data validation, statistical
  testing, power analysis, and automated reporting.
- **Production-focused APIs**: FastAPI-based ML microservice, Kubernetes-ready
  deployment manifests, observability hooks, and CI coverage.
- **Interactive dashboards**: Flask + WebSocket visualizations, GraphQL layer,
  and exportable executive summaries.

## Quickstart

```bash
git clone https://github.com/diogoribeiro7/ds-projects-portfolio.git
cd ds-projects-portfolio
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Run the most common workflows:

```bash
# Launch statistical experiment analysis utilities
python scripts/analyze_experiment.py --help

# Spin up the dashboard locally
python -m dashboard_enhanced.app

# Deploy the ML API locally
uvicorn src.api.ml_api:app --reload --host 0.0.0.0 --port 8000
```
