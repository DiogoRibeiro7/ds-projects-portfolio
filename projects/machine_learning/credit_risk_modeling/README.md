# Credit Risk Modeling (Logistic Regression)

Binary classification example for loan default risk using synthetic data.

## What it covers
- Synthetic tabular data generation
- Train/validation split
- Logistic regression with class weighting
- Evaluation metrics (ROC-AUC, PR-AUC, confusion matrix)

## Run
```bash
python projects/machine_learning/credit_risk_modeling/train.py
```

## Output
- Prints metrics and a short report of model performance.
